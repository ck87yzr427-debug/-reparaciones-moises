# Reparaciones y Soluciones de Moisés

Web de reparaciones del hogar, pequeñas reformas y soluciones creativas a domicilio en Barcelona y Collserola.

## Publicar con GitHub Pages

En Settings → Pages, seleccionar Deploy from a branch, rama main, carpeta / (root), y guardar.

Dirección prevista una vez activada la publicación:
https://ck87yzr427-debug.github.io/-reparaciones-moises/

## Contenido

Presentación, servicios, cuatro proyectos con 11 fotos reales y contacto por WhatsApp. Las imágenes se pueden ampliar. Archivos estáticos, sin instalación ni compilación.

Pendiente: enlazar la ficha de Google Maps y las reseñas cuando esté disponible.
